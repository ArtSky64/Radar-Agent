# AI Радар & Scout ✦ Autonomous AI/ML Recon Core

Современная автономная система мониторинга, векторной дедупликации и интерактивной аналитики ключевых релизов в сфере искусственного интеллекта и машинного обучения.

Система агрегирует данные из первоисточников:
* **Hugging Face** — трендовые мировые и русскоязычные модели и датасеты;
* **ArXiv & Papers with Code** — свежие научные публикации и препринты;
* **GitHub Trending** — трендовые AI-репозитории и библиотеки инференса;
* **LMSys Chatbot Arena** — лидерборд и замеры Elo передовых языковых моделей.

Отсечение информационного шума выполняется через локальную векторную модель **FastEmbed** (косинусный порог сходства 0.59), а веб-интерфейс рабочей станции оснащён встроенным **RAG-ассистентом** с сохранением контекста диалога.

---

## ✨ Основные возможности

1. **Диалоговый RAG-ассистент с удержанием контекста:**
   * **Память диалога:** помнит историю общения и точно отвечает на вопросы о предыдущем контексте (например: *«А что мы обсуждали ранее?»*).
   * **Кнопка «Новый диалог»:** позволяет в один клик начать беседу с чистого листа.
   * **Полноценный Markdown и кликабельные ссылки:** ответы форматируются с заголовками (`#`), жирным шрифтом (`**`), списками, блоками кода и кликабельными гиперссылками (открываются в новой вкладке).
   * **Настройка количества источников:** понятный слайдер «Количество источников в ответе» для регулирования объема контекста из локальной базы знаний (вместо термина Top-K).
   * **Отказоустойчивость (Fallback):** при отсутствии подключения к внешнему LLM-серверу (vLLM/Qwen) ассистент автоматически переключается в локальный векторный режим и продолжает находить релевантные материалы.

2. **Мониторинг 4 ключевых источников:**
   * 7 разделов каталога: Лидерборд Arena, Трендовые модели HF, Модели HF (RU), Papers (Статьи), Датасеты, Репозитории GitHub, ИИ-Рекомендации (RAG).
   * Быстрый поиск по всем материалам через палитру команд (`Ctrl + K`).

3. **Векторная дедупликация FastEmbed:**
   * Локальное вычисление семантических эмбеддингов (384-dim) без внешних API-затрат.
   * Отсечение дублирующихся или незначительных релизов с порогом 0.59.

    ├── dist/                   # Продакшн-сборка интерфейса (HTML/CSS/JS)

## 🚀 Быстрый старт через Docker (Рекомендуется)

Проект полностью упакован в Docker с multi-stage сборкой фронтенда и бэкенда:

```bash
# 1. Клонирование репозитория и переход в папку
cd agent

# 2. (Опционально) Создание конфигурационного файла
cp .env.example .env

# 3. Сборка и запуск контейнера
docker compose up --build -d
```

Сервис запустится и будет доступен:
* **Веб-интерфейс и API:** `http://localhost:8000`
* **Swagger-документация API:** `http://localhost:8000/docs`

Остановка контейнера:
```bash
docker compose down
```

## 💻 Локальная разработка (без Docker)

### 1. Установка Python-бэкенда
Требуется **Python 3.10+**:
```bash
python -m venv venv

# Активация окружения:
# Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# Linux / macOS:
source venv/bin/activate

pip install -r requirements.txt
playwright install chromium
```

### 2. Настройка окружения (.env)
```bash
cp .env.example .env
```
Заполните параметры при необходимости (для базовой работы и локального RAG-поиска внешние ключи не обязательны).

### 3. Сборка и запуск фронтенда
Требуется **Node.js 18+**:
```bash
cd web
npm install
npm run build
cd ..
```

### 4. Запуск приложения
```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```
Приложение откроется на `http://localhost:8000`.

Для активной разработки фронтенда с Hot Module Replacement (HMR):
```bash
cd web
npm run dev
# Доступно на http://localhost:5173 (проксирует запросы на :8000)
```

## ⚙️ Конфигурация (.env)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `VLLM_BASE_URL` | `http://127.0.0.1:2233/v1` | URL OpenAI-совместимого эндпоинта LLM (vLLM / Ollama / OpenAI) |
| `VLLM_MODEL_NAME` | `Qwen/Qwen3.6-27B` | Название модели генерации |
| `VLLM_API_KEY` | `not-needed` | Ключ API для LLM-сервиса |
| `DB_NAME` | `data/app_database.db` | Путь к файлу базы данных SQLite |
| `DUPLICATE_THRESHOLD` | `0.59` | Косинусный порог отсечения дубликатов |
| `VECTOR_DIM` | `384` | Размерность векторов FastEmbed |
| `LOG_FILE` | `data/app.log` | Путь к основному файлу логов |
| `ERROR_LOG_FILE` | `data/errors.log` | Путь к логу ошибок |
| `GITHUB_TOKEN` | — | Токен GitHub API для сбора трендов |
| `HUGGINGFACE_API_KEY`| — | Токен Hugging Face API |
| `KAGGLE_USERNAME` | — | Логин Kaggle API |
| `KAGGLE_KEY` | — | Ключ доступа Kaggle API |

## 📡 Основные REST API эндпоинты

| Метод | Эндпоинт | Описание |
|---|---|---|
| `POST` | `/rag/chat` | Основной диалоговый RAG-эндпоинт с сохранением истории и источников |
| `GET` | `/rag/stats` | Статистика индекса базы знаний (число карточек по категориям) |
| `POST` | `/rag/reindex` | Принудительная переиндексация векторов базы данных |
| `POST` | `/api/v1/rag/query` | Прямой запрос к RAG-ассистенту |
| `GET` | `/trending/models` | Список трендовых моделей Hugging Face |
| `GET` | `/trending/github` | Список трендовых репозиториев GitHub |
| `GET` | `/articles` | Список научных статей и датасетов |
| `GET` | `/leaderboard` | Срез лидерборда LMSys Arena |
| `POST` | `/api/v1/radar/sync` | Запуск фонового сбора данных по всем источникам |
